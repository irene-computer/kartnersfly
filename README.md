## 📋 Features

### Frontend Features
- **Destination Management**: Browse and search travel destinations with detailed information
- **Online Booking**: Book trips directly through the website
- **Contact Form**: Send inquiries with automatic email notifications
- **Newsletter**: Subscribe to receive exclusive offers and updates
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **PWA Support**: Install as a mobile app for offline access
- **Interactive Animations**: Smooth scroll and fade-in effects
- **Social Media Integration**: Links to TikTok, WhatsApp, Instagram, Facebook, LinkedIn, YouTube

### Admin Features
- **Dashboard**: Overview with statistics (messages, bookings, destinations, services)
- **Message Management**: View, read, and delete contact messages
- **Booking Management**: Track and update booking statuses
- **Destination Management**: Add, edit, and delete travel destinations
- **Service Management**: Manage travel services offered
- **User Authentication**: Secure login system for admin access

### Technical Features
- **Email Notifications**: Automatic email confirmation for contact forms
- **Database Integration**: SQLite database for data persistence
- **File Upload**: Support for destination images
- **Security**: Password hashing, CSRF protection, secure sessions
- **Performance**: Caching, optimized assets, lazy loading
- **SEO Ready**: Meta tags, sitemap, structured data
